PedsEnEx

A GTA:SA mod that adds ambient peds walking in and out of buildings.

These docs were reformatted and updated by Claude (Anthropic) from the original README and the mod's current source code. The mod itself is the work of its author, vecondite.

About

PedsEnEx is an extended, much better ASI version of my previous CLEO version of this mod. It no longer requires manual mapping: it ships with over 150 locations configured by default. Inspired by the mod Doorway Life by LKBoss.

I loved the idea of LKBoss' mod, but its customizability was minimal. This version adds features missing from both their mod and my previous CLEO version:

  • Filtering by in-game time
  • Filtering by ped model
  • Ability to add and remove locations
  • Cops coming out of doors (if enabled) when you're wanted
  • Reloading all configs in-game with a cheat code
  • Optional logging and an anti-cramming fix for crowded doorways

How it works

Every location runs this cycle independently:

  1. Player in range? Nothing happens unless the player is within r of the location.
  2. Interval and time check. Once int milliseconds have passed since the last attempt, the in-game clock is checked. Civilians need the time to fall inside the location's time range (trid). Cops need cops enabled (c), a wanted player, and the time inside time range 0. The interval timer only restarts when one of these passes.
  3. Spawn roll. The attempt goes ahead with a chance of prob percent.
  4. Find the door. The nearest door object of model m within r is used and unlocked. If there is none, nothing happens.
  5. Enter or exit roll. A roll against lp percent decides the outcome:
RollResult
SucceedsAn existing ped nearby walks into the door and fades out
FailsA new ped spawns at the door and walks out

Entering peds

The closest ped that is alive, on foot, within r, has a model listed for the location's pid, and does not have one of the last savepeds models is sent to the spot in front of the door and then to the door itself. When its walk finishes, it fades out. If no ped qualifies, lfb decides: 0 does nothing, 1 spawns a new ped walking out instead.

Spawned peds

A new ped appears at the location's coordinates, facing away from the door, and walks walk units out (iw flips the direction). Civilians then get the wandering AI. Cops are armed with a pistol or a nightstick, walk out, and go after the player. If the player is wanted and the cop roll passes, a cop spawns; otherwise a civilian does, unless the location is cops-only (co). With cramfix on, nothing spawns while the door is already open.

Configuration overview

FilePurpose

timeRanges.txtTime ranges for each trid

These files are read from the mod's own folder.

General rules for the .txt files

  • A line is a comment only if its first character starts //, # or ;. Inline comments are not supported.
  • Empty lines are skipped. Whitespace around values is ignored.
  • In locations.txt, fields are separated by spaces or tabs.
  • In the other three files, each line is id = value,value,... with exactly one =.
  • Reload in-game: type the cheat from config.ini (default PENEX) to reload every file without restarting.
  • The -1 fallback: pedModels.txt, copModels.txt and timeRanges.txt accept an ID -1 entry, used when a location refers to an ID that doesn't exist.

Common pitfalls

ProblemResult
A locations.txt line without exactly 18 fieldsSilently skipped
No -1 in pedModels.txt or copModels.txt, and an undefined ID is usedEmpty model list, which can crash the game on spawn
No 0 entry in timeRanges.txtCops never spawn
No -1 in timeRanges.txt, and an undefined ID is usedPeds never spawn at that location
A comment after data, or indented before //Treated as data; the line is skipped or breaks parsing
Missing or non-numeric keys in config.iniCan crash the game on load

config.ini

If the file doesn't exist, the mod generates it with these defaults and shows a message box.

[settings]
cheat = PENEX
cramfix = 1
savepeds = 3
logging = 0
KeyDefaultDescription
cheatPENEXCheat code typed in-game to reload locations.txt, pedModels.txt, copModels.txt, timeRanges.txt and config.ini. A message shows how many locations loaded and your settings. Use uppercase letters, like normal GTA cheats.
cramfix1Stops peds spawning while the door is already open, so they don't cram into the doorway. 0 disables it.
savepeds3How many recently used ped models are remembered. Existing peds with those models aren't picked to walk into a door, so a ped that just came out doesn't turn straight back in. Keep this at 1 or higher.
logging0When 1, each spawn appends a line to PedsEnEx.log with the model, location id and coordinates. The log is cleared at game start. Peds walking into doors aren't logged.

locations.txt

Defines all the locations where peds spawn. Every line must have exactly 18 fields, separated by spaces or tabs; any other line is silently skipped.

id(0) x(1) y(2) z(3) r(4) m(5) int(6) prob(7) walk(8) wt(9) iw(10) pid(11) trid(12) c(13) cp(14) co(15) lp(16) lfb(17)

Example:

1 1979.554688 -2036.890625 12.539062 20.0 1532 30000 100.0 2.5 60000 0 -1 -1 1 15.0 0 40.0 0
All probabilities (prob, cp, lp) are percentages from 0 to 100.
#FieldTypeDescription
0idintegerIdentifier of the location. Only used to tell locations apart in the log; keep it unique.
1-3x y zfloatCoordinates of the location. Peds appear here, and entering peds end up here.
4rfloatRadius. Peds only spawn if the player is within it, only peds within it enter the door, and the door is searched for within it.
5mintegerModel of the door. The closest object of this model within r is used; if there is none, nothing happens.
6intinteger, msInterval at which the spawning logic fires.
7probfloat, %Probability a ped will spawn when a spawn request fires.
8walkfloatDistance the ped walks to exit the door. After moving this far it gets the wandering AI.
9wtinteger, msMaximum time a ped can spend walking (out or in) before it is teleported to the destination. This is a maximum, not a forced wait, so a high value is recommended.
10iwbooleanInverts the walk destination. Set to 1 if the ped walks towards the wall instead of the door. Useful for interior locations.
11pidintegerID in pedModels.txt. Only peds with those models spawn here and enter the door. Falls back to -1.
12tridintegerID in timeRanges.txt. Falls back to -1.
13cintegerCop switch and ID in copModels.txt. 0 or lower disables cops at this location.
14cpfloat, %Probability a cop spawns when the player is wanted, multiplied by the number of stars. With 15.0: 15% at one star, 45% at three, 90% at six.
15coboolean1 if the location only has cops spawning.
16lpfloat, %Probability a ped will enter (from outside) or leave (from inside). On success an existing nearby ped walks into the door; on failure a new ped walks out.
17lfbbooleanLeave fallback, used when no ped is found in the radius to enter or exit. 0: nothing happens. 1: a ped walks out (from outside) or in (from inside).

For cops to spawn at a location, all of these must be true: c is above 0, the player is wanted, time range 0 contains the current in-game time, and the cp roll succeeds.

pedModels.txt

Defines the ped model IDs for each pid in locations.txt. The list controls which models spawn as new peds and which existing peds may walk into the door.

id = int,int,int

1 = 120,121,122

With the example above, set pid to 1. ID -1 is the fallback entry, used when a location's ID isn't found. Always define it: with no fallback an undefined ID gives an empty list, which can crash the game on spawn.

If a model can't be loaded, an on-screen message reading Failed to load ped model: <id> appears and no ped spawns. Enable logging to find the location.

copModels.txt

Defines the cop model IDs for each c ID in locations.txt.

id = int,int,int

1 = 120,121,122

With the example above, set c to 1. ID -1 is the fallback entry; always define it, for the same reason as above.

Do not use ID 0. Setting c to 0 in locations.txt is the hardcoded switch that disables cops for that location. Cops also need a time range 0 in timeRanges.txt.

timeRanges.txt

Defines the time ranges for each trid. Times use the 24-hour format (HH:MM) and both ends are inclusive. ID 0 is the range for cops; ID -1 is the fallback.

id = timeStart-timeEnd,timeStart-timeEnd

// peds spawn all day
-1 = 00:00-23:59
// cops may spawn at any time
0 = 00:00-23:59
// morning and evening rush
1 = 06:00-09:00,16:00-19:00
// 22:00 to 05:00 (split at midnight)
2 = 22:00-23:59,00:00-05:00

timeStart must be lower than timeEnd, so a range can't wrap past midnight; split it in two as shown. If there is no 0 entry, cops never spawn.

Support and license

If you need help with the mod, contact me on Discord: vecondite. Bug reports and contributions are very much appreciated and welcome. Before reporting a crash, double-check your config files. If the problem involves a specific spawn, set logging = 1 in config.ini and include PedsEnEx.log in your report.

The mod still uses some CLEO opcodes, such as defining task sequences for walking peds and door unlocking with 0905. If you know the plugin-sdk alternatives, please let me know.
